# The gripper from 1 to 0 is open, and from 0 to 1 is close, the gripper default state is 0.
# The target_rotation defaults to the opposite direction of the normal of the object
# The affordance_map is set to 1 at the position that need to be moved
# The avoidance_map is set to 1 at the position that need to be avoided

Variable Descriptions:
    obs_dict["name"] # object name
    obs_dict["position"] # The position represents the center of the object in the voxel frame, center_x, center_y, center_z = object['position']
    obs_dict["aabb"] # The aabb represents minimum and maximum coordinates in the voxel frame, (min_x, min_y, min_z), (max_x, max_y, max_z) = object['aabb']
    obs_dict["_position_world"] # The _position_world represents the center of the object in the world frame


Function Descriptions:
    Function cm2index(cm, direction): Used to convert centimeters to voxel indices.
    Function set_voxel_by_radius(voxel_map, voxel_xyz, radius_cm=0, value=1): given a 3D np array, set the value of the voxel at voxel_xyz to value. If radius is specified, set the value of all voxels within the radius to value.
    Function rotate_pose_local_axis(rotvec, axis='x', angle_deg=30, degrees=False): Rotates a rotation vector around a specified local coordinate axis (‘x’, ‘y’, or ‘z’) by a given angle; the rotation is applied in the local frame of the current orientation, using axis-angle representation. 


# Initial End-Effector Pose (Local Frame):
- The end-effector’s local Z-axis points vertically downward (toward the ground).
- The local X-axis points forward (in the direction the gripper is facing).
- The local Y-axis points to the left (completing the right-handed coordinate system: X forward, Y left, Z down).

# Base Frame (World Coordinate System):
- The base X-axis points to the right and slightly upward (diagonally forward-right in world space).
- The base Y-axis points to the left and slightly upward (diagonally forward-left in world space).
- The base Z-axis points vertically upward (perpendicular to the ground, opposing gravity).

Note: All rotations (e.g., via `rotate_pose_local_axis`) are applied in the **end-effector’s local frame**, not the base/world frame. For example, rotating around the local Y-axis will tilt the gripper sideways relative to its own forward direction, regardless of global orientation.
